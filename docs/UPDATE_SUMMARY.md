## 技术细节

### 版本检查机制

1. **当前版本检测**
   - 优先读取`KERNEL_VERSION`文件
   - 备选：解析内核`Makefile`
   - 兜底：使用默认版本5.4.86

2. **最新版本获取**
   - 从kernel.org CDN获取补丁列表
   - 解析所有5.4.x版本
   - 排序获取最新版本

3. **版本比较**
   - 格式：major.minor.sublevel
   - 仅支持同一分支内的更新
   - 跨分支更新不支持（安全考虑）

### 增量补丁应用

**更新流程：**
```
5.4.86 → 5.4.87 → 5.4.88 → ... → 5.4.302
```

每个步骤：
1. 下载补丁：`patch-5.4.X-Y.xz`
2. 解压补丁
3. 应用补丁：`git apply`
4. 处理冲突（如果有）
5. 更新Makefile版本号

**冲突处理：**
- 自动尝试`git apply --reject`
- 生成`.rej`文件显示冲突
- 保留冲突文件供手动解决
- 不中断更新流程

### Git集成

**自动提交：**
```bash
chore: update kernel to 5.4.XXX

- Applied incremental patches from kernel.org
- Updated SUBLEVEL in Makefile
- Generated by auto-update script
```

**标签格式：**
```
kernel-v<version>-<date>
```

示例：
- `kernel-v5.4.86-20260308`
- `kernel-v5.4.302-20260315`

## 已知问题

### 补丁冲突

**问题：** 从小米vendor内核应用到upstream补丁时可能冲突

**解决：** 
- 脚本会自动尝试解决
- 生成的`.rej`文件显示冲突位置
- 需要手动解决后继续

### 跨版本更新

**建议：** 一次更新一个大版本号

**示例：**
```bash
# 推荐
./update-kernel.sh update 5.4.100
# 测试通过后
./update-kernel.sh update 5.4.200

# 不推荐（冲突概率高）
./update-kernel.sh update 5.4.302
```
